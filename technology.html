Technology & Computing

I’m interested in how things work: how browsers render a page, how local models fit into memory, and how a game’s feel depends on the machine running it.

A small web

HTML gives a document its structure, CSS gives it a reading rhythm, and JavaScript adds interaction where it helps. I like the independence of a site that can be kept as files, read offline and moved between hosts. Git records the history of changes, while GitHub can serve as a place to keep and publish them.

Python is useful for working with source lists, cleaning tabular data and exploring historical or genetic datasets. The question that interests me is how to make the result easy for someone else to inspect.

Local AI and model formats

Running large language models locally brings the trade-offs into view. Ollama offers a local runtime, and GGUF packages weights and model metadata in an ecosystem commonly used for quantized inference. Memory requirements depend on the weights, context length and runtime. Comparing output quality, tokens per second and memory use gives a fuller picture than comparing model file sizes alone.

Hardware and gaming technology

CPU scheduling, GPU memory, cooling, storage and display refresh affect different workloads in different ways. For games, frame pacing and input latency can matter as much as average frame rate. Software experiments are most informative when a change is isolated and the same scenario can be repeated.
